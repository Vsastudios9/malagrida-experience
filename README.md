# Malagrida Experience Design

Create a premium restaurant website for "Malagrida Restobar", located in Boipeba, Bahia, Brazil.



IMPORTANT:

This is not a generic restaurant website.

The website must communicate a sophisticated but welcoming atmosphere, combining high-quality gastronomy, signature drinks, island culture, and unforgettable experiences.



DESIGN STYLE



Use a luxury fine dining aesthetic inspired by boutique restaurants and modern hospitality brands.



Visual direction:

- Elegant

- Warm

- Authentic

- Premium

- Sophisticated

- Tropical luxury

- High-end restaurant



Avoid:

- Generic restaurant templates

- Bright colors

- Cheap visual effects

- Excessive animations

- Corporate appearance
